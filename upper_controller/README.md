## v3 参数读写

实机验证更新（2026-11-12）：已在 COM4、1600 脉冲/转的正式 v3 固件上完成四轴 SET/GET 回读、参数修订号和轴间隔离测试，超范围参数拒绝通过。测试后已恢复各轴原参数，指令位置、已发脉冲和完成计数均未变化，全程未发送 MOVE/RUN。记录见 `backups/parameter-v3-com4-test-20261112.json`。

本版要求 PROTO=3 固件。连接后自动读取四轴板端参数。修改输入框只改变草稿，必须点击“写入参数”；收到板端回读且一致后才允许启动。正反向启动发送 RUN，使用下位机保存的参数。“读取参数”会用板端值覆盖该轴输入框。

读写包括位移、速度、加速度、减速度、曲线类型，每轴独立。保存位置是 MCU RAM，复位或断电恢复默认值；不写驱动器或 Flash。REV 表示当前启动周期内的参数修改次数。

原来的左图“等待数据”也可能由输入无效引起。现已区分错误原因：加减速度仍限 1～120rpm/s，输入 200 无效，不能写入或启动。右图在已连接但空闲时正常显示零速度线。

```text
SET 1 1600 30 40 50 TRAP
GET 1
RUN 1 1
RUN 1 -1
PARAM 1 STEPS=1600 RPM=30 ACC=40 DEC=50 CURVE=TRAP REV=1
```

SET 不启动运动；运行中的轴拒绝 SET。GET 可读取运行轴的配置参数。旧的 MOVE 保留为即时运动命令，不改变已写入参数。下文 v2 信息是首版历史记录，当前版本使用 v3。

第一版支持四轴独立定位，可让多轴分别运行，但不提供直线/圆弧插补或轨迹同步。程序使用 Python Tkinter + pySerial，已打包 Windows 可执行文件。

## 直接打开

双击仓库根目录的 `启动四轴上位机.cmd`，或运行：

```text
output/upper_controller/YSF4Pro_Controller.exe
```

当前未接串口时，点击“离线演示”。演示模式会明确显示“离线演示 · 不连接硬件”，不会打开任何串口，可用于试用四轴切换、不同参数、同时运行、停止及曲线。

## 四轴操作

1. 点击左侧轴 1～4，选中要操作的轴。
2. 设置相对位移（脉冲或转）、速度、加速度、减速度和曲线。
3. 点击正向启动或反向启动，每次执行有限距离定位。
4. 可以切换另一轴，启动独立运动。切换本身不会发送运动或停止命令。
5. 本轴停止仅作用于当前轴；全部轴停止请求所有轴减速停止。

每轴的输入参数独立保存在当前应用会话中；重启恢复默认值。运动中新的本轴 MOVE 会被拒绝，其他空闲轴仍可操作。“软件置零”不执行机械回零；“清软件故障”不能清除 CL57C 本体报警。

## 接入真实硬件

1. 开发板已刷入配套四轴 v2 固件，上电不自动运行。
2. 用 USB 数据线连接开发板 **USB2 Mini USB 串口口**，接通 JP2，确认设备管理器出现 COM 口。
3. DAP 负责烧录，不是本程序的通信通道。
4. 选择 COM 口，点击连接设备。通信使用 115200、8N1。
5. 程序校验握手中的 PROTO=2、AXES=4 和每转脉冲数，旧版单轴固件不会启用运动按钮。
6. 首次只操作实际连接的轴，以小位移、低速确认方向。

| 上位机轴号 | 开发板接口 | PUL / 定时器 | DIR | EN，暂不由界面切换 |
|---|---|---|---|---|
| 1 | CN16 | PI5 / TIM8_CH1 | PD3 | PD7 |
| 2 | CN17 | PI6 / TIM8_CH2 | PD11 | PF11 |
| 3 | CN18 | PI7 / TIM8_CH3 | PF1 | PF2 |
| 4 | CN19 | PI2 / TIM8_CH4 | PC8 | PH7 |

四个接口各自的端子顺序均为：1 EN−、2 EN+、3 DIR−、4 DIR+、5 PUL−、6 PUL+。按同名信号接驱动器，信号电源跳线及 5V 输入档仍按[开发笔记](../docs/步进电机开发笔记.md)设置。

默认每转 1600 指令脉冲，可在“细分与光电开关”页按轴配置并手动确认与驱动器一致。下位机仍使用 1600 参考值，位移范围 1～32000 脉冲、速度报文值 1～60、加减速度报文值 1～120、单次规划不超过 120 秒；界面的实际速度及加减速度范围按每轴细分换算。

## 曲线与状态

- 左侧曲线：下一次移动的规划预览，尚未发给下位机。
- 右侧曲线：从下位机读取的指令速度，保留最近 30 秒。
- 两者都不是编码器实际速度。本版没有把电机编码器或驱动器报警反馈送回上位机。
- S 型采用对称五次多项式位置规划，没有单独的 Jerk 设置和匀速平台；加减速度中较小值限制两侧。
- 切轴后曲线和状态跟随对应轴，其他轴继续运行。
- 状态超过 1 秒未更新时显示过期并禁用启动；连接成功会启用下位机 1.5 秒通信超时减速停止。
- 主动断开/关闭时发送 STOP ALL，并等待有限时间接收确认。断电、线缆断开等情况无法保证该命令送达，因此还有通信超时机制。软件停止不能替代机械设备所需的安全急停。

## 协议 v2

```text
HELLO
MOVE 1 1600 30 30 30 TRAP
MOVE 4 -1600 20 40 40 S
STATUS
STATUS 2
STOP 2
STOP ALL
ZERO 3
CLEAR 3
WATCHDOG 1500
```

每条命令末尾发送 LF。WATCHDOG 只支持 0 或 1500，默认关闭；上位机连接成功后启用，250ms 查询一次状态。旧版不带轴号的 MOVE/STOP/CLEAR/ZERO 仍路由至轴 1。

```text
HELLO YS_F4Pro AXES=4 PROTO=2 PPR=1600 RPM_MAX=60 STEPS_MAX=32000
OK MOVE 4
ERR BUSY 4
STATE 4 RUNNING POS=-420 PULSES=420/1600 RPM_MILLI=20000 FAULT=0 DONE=0 T=3000
```

RPM_MILLI 是 rpm 的千分之一，T 是 MCU 运行毫秒数，DONE 是该轴完成次数。停止导致的目标脉冲减少会体现在 PULSES 的分母中。
