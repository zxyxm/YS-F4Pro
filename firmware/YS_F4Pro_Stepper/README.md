# YS-F4Pro 四轴 HAL 固件 v3（历史）

当前版本已扩展为 CN16～CN19 四轴独立运动。v3 新增每轴 RAM 参数：SET 写入并自动回读，GET 读取，RUN 使用板端参数启动。SET 不产生运动；运行中的轴拒绝修改，复位或断电恢复默认参数。板端协议为 PROTO=3，配套上位机要求参数同步后才允许启动。

当前完整说明见[四轴上位机操作说明](../../upper_controller/README.md)。下文保留单轴首版历史说明，旧 MOVE 格式仍兼容轴 1；现在四轴均可独立输出脉冲。

硬件：STM32F407IGT6、CN16、CL57C、57CME23；1600 指令脉冲/转，5V 输入，单脉冲＋方向模式。只有 CN16 第一轴会输出脉冲。

这是使用资料中 ST HAL/CMSIS 建立的独立 CMake 工程，**不是 CubeMX 自动生成工程，目前没有 `.ioc`**。启动文件为依据 ST 设备头文件构建的 GCC C 启动代码，Flash 1MB、常规 SRAM 128KB。不要直接用 CubeMX 覆盖本目录；如需图形配置，先在另一目录生成再逐项迁移。

## 上电后的行为

- LED1 每 500ms 翻转一次。
- 上电不自动转动；定时器保持停止，等待按键或串口指令。
- 开机执行运动规划计算自检，不产生电机脉冲；失败进入软件故障状态。
- EN 输出 PD7 默认低电平。首次建议驱动器 ENA 两端不接，后续确认实际极性再使用。
- 原点没有连接和搜索；软件位置零不代表机械原点。

## 直接用开发板按键

| 按键 | 行为 |
|---|---|
| KEY1 / PE0 | 正向一圈，梯形，目标 30rpm |
| KEY2 / PE1 | 减速停止 |
| KEY3 / PE2 | 反向一圈，梯形，目标 30rpm |
| KEY4 / PE3 | 正向一圈，五次多项式 S 型定位 |

默认加速度与减速度各 30rpm/s。正向是软件定义，实际轴转向取决于驱动器设置。运动中忽略新的按键移动请求。按住按键不会重复启动；上电时已按住的键也不会自动启动，需释放后再按。

KEY2 是普通软件减速停止，不能当作安全急停。首次空载并固定电机，先短按 KEY1；若驱动器报警，停止测试查接线及拨码，不要反复加速。

## 串口命令

电脑通过板载 USB2 串口连接，JP2 接通；USART1 PB6/PB7，115200、8N1。DAP USB 连接与 USB2 数据线是两条不同通道，本固件未启用 DAP 虚拟串口通信。

每条命令末尾发换行 LF，可带 CRLF。数值采用十进制整数。

```text
PING
STATUS
HELP
MOVE 1600 30 30 30 TRAP
MOVE -1600 30 30 30 TRAP
MOVE 1600 30 30 30 S
STOP
CLEAR
ZERO
```

MOVE 参数：有符号相对脉冲数、目标 rpm、加速度 rpm/s、减速度 rpm/s、曲线类型。脉冲幅值 1～32000、速度 1～60rpm、加减速度 1～120rpm/s；规划时长超过 120 秒则拒绝。

- `TRAP`：支持独立加减速度，短距离自动降峰值成为三角形。
- `S`：五次多项式位置曲线，平滑起停，无单独匀速平台；按速度及加减速度上限选择总时长。采用对称曲线，使用加减速度中较小值限制两侧，不是可独立设置 Jerk 的七段 S 曲线。
- `STOP`：从当前规划速度转为梯形减速停止，包含 S 型运动期间的停止。
- `CLEAR`：仅在空闲时清除 MCU 软件故障，不清除驱动器报警。
- `ZERO`：仅将软件指令位置置零，不执行机械回零。
- `STATUS`：返回状态、指令位置、已发脉冲/本段总脉冲、速度（千分之一 rpm）及软件故障。

运动中新的 MOVE 返回 BUSY。完成返回 DONE。所有位置与速度都是指令数据，本固件未读取实际编码器反馈，也未接入 CL57C 报警和机械限位。

## 实现与故障

TIM8_CH1 / PI5 使用输出比较。定时器 1MHz，硬件翻转生成 40μs 有效脉冲；较长等待分成多段，等待阶段不翻转。PD3 是方向，启动前等 1ms。最后一个脉冲结束后才停止输出。串口和按键不会在中断中执行整段运动。

`g_fault`：0 正常；1 比较事件安排过晚；2 定时器启动失败；3 间隔不足；99 初始化或异常处理故障。发生软件故障后不会接受新运动，先检查再 CLEAR 或复位。驱动器本体报警需另按实际 CL57C 手册排查。
