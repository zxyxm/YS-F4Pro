# 电机与 LED 合并版使用、结构与协议

2026-11-17，版本 v5。上位机 `combined_controller`，下位机 `firmware/YS_F4Pro_Combined`。之前独立 LED、电机目录作为历史例程保留，合并版不依赖它们运行。

## 快速操作

1. DAP 下载合并固件。电脑 USB2 串口连接开发板，JP2 两路串口跳帽接通。DAP 与 USB2 串口作用不同。
2. 运行“启动电机LED上位机.cmd”，选择实际 COM 口（本次 COM4），连接成功后显示电机+LED v5。首次从源码使用需先安装依赖，EXE 需自行打包，见[上位机说明](../combined_controller/README.md)。
3. “四轴电机”：选择轴及位置/速度模式。位置模式先写入参数、等待回读一致后启动；速度模式直接发送当前速度和加减速度，持续至停止。四轴分别独立启停，模式切换页签不停止其他轴。
4. “LED 与流水灯”：三个灯各有点亮/熄灭；支持全部开关。间隔 50～60000ms，方向正/反，循环 0～9999 次，0 表示无限。写入设置后暂停；重新开始从 LED1、0 圈运行。三个灯各亮一个间隔算一圈，完成后熄灭。读取设置将板上值填回输入框。

速度上限 200 rpm，加减速度上限 400 rpm/s，默认仍为 30/30/30。3200 脉冲/转时 200 rpm 对应理论 10666.67Hz。PUL 显示的是定时器调度周期换算，未回接测量外部信号；周期量化会带来小幅误差，参见[电机频率说明](电机v4速度模式与PUL频率.md)。

关闭统一上位机时发送 STOP ALL，电机减速停止；LED 保持当前模式。通信看门狗连接后设置为 1500ms，通信中断请求电机减速停止。参数只保存在 RAM，复位/断电恢复默认。LEDRESET 只恢复 LED，不复位芯片，不修改或停止电机。

## 引脚与按键冲突处理

| 功能 | 引脚/接口 |
| --- | --- |
| LED1、LED2、LED3 | PH9、PE5、PE6，高电平点亮 |
| KEY1～KEY5 | PE0～PE4，低电平按下 |
| UART1 TX/RX | PB6/PB7，USB2 串口，115200 8N1 |
| 四轴 PUL | PI5、PI6、PI7、PI2，TIM8 CH1～CH4，CN16～CN19 |
| 四轴 DIR | PD3、PD11、PF1、PC8 |

LED1 的旧电机心跳被移除，不会覆盖 LED 控制。实体按键仅控制 LED：KEY1 暂停/继续，KEY2 换向，KEY3 加快，KEY4 减慢，KEY5 默认。电机由上位机控制；不保留旧版实体按键启动电机的映射。不要把 KEY2 当成合并版电机停止键。

## 下位机结构

`main.c` 管理时钟、统一 GPIO、USART1、TIM8、四轴电机和总串口解析；`motion_plan.c` 计算梯形、S 定位及减速停止；`led_app.c` 管理流水状态和命令；`bsp_key.c` 处理五键去抖；`bsp_led.c` 操作三灯。

启动：HAL → 时钟 → 运动规划计算自检 → 硬件 → 按键与 LED 初始化。上电 LED 为 300ms 正向无限流水，电机全空闲。主循环依次处理串口、LED 按键、LED 计时、通信看门狗及电机完成反馈。高优先级 TIM8 中断独立执行 PUL，不使用主循环延时生成脉冲。

四轴遥测输出较长，串口发送拆分成每块最多 32 字节，并在块间服务 LED 计时，避免短流水间隔被一次整批状态发送长期阻塞。GPIO 开关、LEDRESET 不修改 TIM8 或电机参数。

## 上位机结构

组合入口 app.py 建立同一窗口的两个页签；电机界面 motor_app.py 与灯光界面 led_panel.py 共用 transport.py 的一个后台线程、一个串口句柄和一条有界发送队列。后台轮询 STATUS，把 STATE、PARAM 和 LEDSTATE 分发给各自界面。断开/过期后控制禁用，LED 显示未知。

旧独立上位机分别要求不同固件协议，不能混用。不要同时打开多个程序占用同一 COM 口。本机细分沿用原电机上位机的配置文件；各轴须确认与驱动器 3200 脉冲/转一致。软件细分设置不会远程修改驱动器拨码。

## 统一报文

ASCII、一行一条，末尾 LF 或 CRLF。

```text
HELLO
HELLO YS_F4Pro AXES=4 PROTO=5 PARAMS=1 PPR=3200 RPM_MAX=200 ACC_MAX=400 STEPS_MAX=32000 SPEED=1 LED=1
```

| 命令 | 作用 |
| --- | --- |
| STATUS | 返回四条电机 STATE 和一条 LEDSTATE |
| STATUS 1、GET 1 | 单轴运动状态、定位参数 |
| SET 1 3200 30 30 30 TRAP | 写入轴 1 定位参数并回读，不产生运动 |
| RUN 1 1、RUN 1 -1 | 用保存的定位参数正/反启动 |
| SPEED 1 1 200 400 400 | 轴 1 正向连续运行，速度/加速/减速 |
| STOP 1、STOP ALL | 单轴/全部电机减速停止，不修改 LED |
| LEDSTATUS | 只返回 LEDSTATE |
| LED 1 ON、LED 3 OFF | 单灯开关，进入 LED 手动模式 |
| ALL ON、ALL OFF | 三灯全部开关，不涉及电机 |
| FLOW CONFIG 300 1 5 | 每灯 300ms、正向、5 圈，写入后暂停 |
| FLOW START、FLOW PAUSE | 流水启动/继续、暂停 |
| FLOW RESTART、FLOW STOP | 从 LED1 重新计数、停止清零熄灭 |
| LEDRESET | LED 恢复 300ms 正向无限流水，不复位 MCU |

保留 MOVE、CLEAR、ZERO、WATCHDOG 等电机命令和 FLOW MS、FLOW DIR 等灯光命令。LED 命令成功返回 OK LED 或 OK LEDRESET，再返回 LEDSTATE；非法灯光命令返回 ERR LED COMMAND。合并版不接受含糊的裸 RESET，使用 LEDRESET。

STATE 沿用 MODE/PUL_HZ_MILLI 的 v4 格式，LEDSTATE 沿用 LED 专用例程字段。它们分别表示指令状态和 GPIO 输出状态，不是电机编码器或光学反馈。光电开关功能仍未接入真实限位保护。

## 编译、验证与边界

仓库根目录 VS Code 默认构建、调试目标改为合并工程。工具路径为本机 STM32Tools 配置，换电脑需调整。编译下载和打包命令见上下位机 README。-O2 优化保持高转速中断时序，保留调试符号，但单步时可能跳行。

2026-11-17 验证：20 项单元测试；离线 GUI 同时运行 200 rpm 模拟电机与 LED 有限循环、读写设置、页签切换、默认/最小窗口布局；板内无 PUL 输出测试中四轴最高速度、停止、梯形/S 定位与 LED 计时共存，两项自检结果均为 0。正式固件下载校验通过，COM4 验证三灯单独/全部控制、有限循环、四轴 200/400 参数读写及操作隔离，真实 GUI 共享连接通过；电机位置和计数未改变，未启动实际电机。

实际电机带载最高速度、加速度以及实体按键仍需人工验证。软件停止不替代硬件急停。
