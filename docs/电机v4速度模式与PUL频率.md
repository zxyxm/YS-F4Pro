# 电机 v4：3200 脉冲/转、速度模式与 PUL 频率

更新日期：2026-11-17。配套源码：`upper_controller` 与 `firmware/YS_F4Pro_Stepper`。LED 工程保持独立；同一开发板每次只能运行一种固件。

## 每转脉冲数

按驱动器实际配置统一为 **3200 脉冲/转**。3200 个指令脉冲对应一圈；频率关系为 `Hz = rpm × 3200 ÷ 60`，30 rpm 对应 1600 Hz，60 rpm 对应 3200 Hz。

上位机协议基准、下位机换算、默认定位位移均为 3200。每轴“细分与光电开关”中的值也应为 3200；这只修改软件换算，不会修改驱动器拨码。现有本机设置已备份至 backups 后统一为 3200，其他电脑上请自行确认驱动器和软件一致。

## 速度模式操作

1. 使用新版电机上位机，选择 COM 口，连接四轴 v4 固件。
2. 选择轴，在轴标题旁切换为“速度模式”。各轴模式分别保存于本次上位机会话。
3. 输入目标速度、加速度、减速度；在当前 3200 细分下范围为 1～200 rpm、1～400 rpm/s。
4. 点击“正向启动”或“反向启动”。从静止加速到目标速度后持续运行，不按位移结束。
5. 点击“本轴减速停止”或“全部轴减速停止”。停止后可修改速度并再次启动；本版不支持运行途中直接改速或反向。

速度模式采用梯形加减速，位移、位移单位和定位 S 曲线不参与运算，相关输入禁用；启动时直接发送当前速度和加减速度，无须点击定位模式的“写入参数”。速度命令不覆盖板上的定位参数。切回位置模式后沿用定位参数读写和回读确认流程。

连接后的通信看门狗为 1500ms，通信中断时请求各轴减速停止。速度模式也受此机制约束。关闭上位机会发送 STOP ALL。软件停止不是硬件安全急停。指令位置接近 int32 边界时速度模式会自动请求减速停止，以避免位置溢出。

## PUL 显示的含义

界面显示“PUL … Hz（定时器）”，读取下位机当前脉冲调度周期，按 `1,000,000 / 周期微秒` 换算。空闲显示 0；升降速时随脉冲周期变化，串口约 250ms 更新。

这是定时器编程输出频率，未回接测量驱动器端子，不是编码器测速，也不能诊断断线或驱动器漏收。首次脉冲等待期显示的是等待周期；停止后的值归零。TIM8 的 1μs 周期量化会带来小幅频率误差，例如理想 312.5μs 取整到 313μs，约 3194.89Hz。需要电气实测时使用合适的示波器/逻辑分析仪或专门的隔离回接电路。

## 报文

本次升级为 **PROTO=4**，上位机只接受 3200 PPR、支持 SPEED 的 v4 固件，避免误接 LED 或旧版电机固件造成单位错误。

```text
HELLO
HELLO YS_F4Pro AXES=4 PROTO=4 PARAMS=1 PPR=3200 RPM_MAX=200 ACC_MAX=400 STEPS_MAX=32000 SPEED=1

SPEED 1 1 30 30 30
OK SPEED 1

STATUS 1
STATE 1 RUNNING POS=100 PULSES=100/4294967295 RPM_MILLI=30000 FAULT=0 DONE=0 T=1000 MODE=SPEED PUL_HZ_MILLI=1600000

STOP 1
STOP ALL
```

`SPEED axis direction rpm accel decel`，方向为 1/-1，轴为 1～4。运行中再次启动返回 BUSY。连续运行以 4294967295 作为目标哨兵；减速停止时转换为有限的剩余减速脉冲。STATE 的 MODE 为 SPEED 或 POSITION，减速过程复用定位减速引擎，会显示 POSITION；PUL_HZ_MILLI 为频率乘 1000。

位置模式的 SET/GET/RUN/MOVE 命令仍可使用，默认 STEPS=3200，位移上限仍为 32000 脉冲。运行状态新增两个字段，上位机解析支持扩展字段。新上位机不能连接旧 v3，旧 EXE 请更换为重新打包的版本。

## 验证记录

2026-11-17：15 项单元测试和界面测试通过，覆盖 3200 换算、连续模式超过一圈持续运行、方向、独立停止、频率换算及参数范围检查。

硬件测试固件把全部 PUL 引脚固定为 GPIO 低电平，仅运行内部定时器：四轴位置及连续速度引擎、最大速度、减速停止检查通过；读取 g_motion_selftest_result 和 g_engine_test_result 均为 0。随后已刷回正式 v4 并校验，通过 COM4 握手、四轴参数/空闲状态及非法速度命令拒绝检查。未发送真实运动指令；电机带载及外部端子频率未实测。

## 200 rpm / 400 rpm/s 上限更新

2026-11-17：定位和速度模式上限统一为 200 rpm、加减速度 400 rpm/s，默认仍为 30/30/30。3200 脉冲/转时理论最大频率 10666.67Hz，定时器整数周期 94μs 对应约 10638.30Hz。PUL 高电平时长由 80μs 缩短为 40μs，以增加低电平与中断调度余量；采用 -O2 编译优化，调试符号保留，调试单步时可能跳行。

四轴 PUL 保持 GPIO 低电平的板内测试覆盖：四轴 200 rpm、400 rpm/s 连续运行与减速停止，以及四轴 32000 脉冲、梯形/S 曲线混合定位。两个自检结果均为 0。正式固件不会上电自启动；尚未实测电机带载达到 200 rpm 的稳定性。
